# RL GridWorld Solver - GitHub Repository\n\nA reinforcement learning environment for solving Markov Decision Processes using classical dynamic programming, specifically **Policy Iteration** and **Value Iteration** algorithms.\n\n## Project Structure\n\n### Core Modules\n- `gridworld_env.py`: The main environment that defines the grid-world with terminal states (top-left `(0,0)` and bottom-right `(size-1, size-1)`)\n- `agents/` directory containing: \n  - `policy_iteration.py`: Policy iteration implementation using the Bellman equation\n  - `value_iteration.py`: Value iteration algorithm\n  - `__init__.py`:\n    - `policy_iteration()` - factory function returning policy_iteration\ndefault selected ('iteration')\n  - `value_iteration()` - factory function returning value_iteration\ndefault selected ('iteration')\n\n### Reward Structure Fixes\n\nThe bug fix in `gridworld_env.py` (lines 94-97) corrected the reward assignment for terminal state transitions:\n\n**Before:**\n```python\nreward = 0.0 if next_state in self.terminal_states else -1.0\n```\n\n**After (bug fixed):**\n```python\n# Always assign -1.0, including for final transition to terminal\nreward = -1.0  # Every step incurs a cost, including the transition to terminal state\n```\n\nThe root cause was that transitions into terminal states were incorrectly giving immediate reward of 0 instead of -1.\n\nThis ensures proper Bellman equation semantics where each step incurs a penalty, making the episode terminate with the expected negative cumulative reward penalty.\n\n## Algorithm Implementations\n\nImplementations follow the following core concepts:\n\n- **Policy Iteration**: Computes optimal policy by alternating value evaluation and policy improvement\n- **Value Iteration**: Sequential optimization using Q-values and the Bellman optimality equation\n- Both handle stochastic and deterministic action spaces consistently\n\n## Testing\n\nRun standard tests with:\n```bash\n# Non-interactive (off-screen) test\ntest_run.py\n\n# Custom selected mode\nexample: python rl_gridworld.py --selected 1 for value iteration\n--selected 2 for policy iteration\n\n## Key Features\n\n- Episodic task semantics with terminal states at opposite corners\n- Support for both stochastic and deterministic policies\n- Modular agent implementations for independent testing\n- Backward compatible API preserved across all versions\n\n## Development Notes\n\n- Stochastic mode: All steps have cost γ × future reward, where transition probabilities for non-stochastic actions are controlled by the user parameter\n- Deterministic mode: Single outcome with probability 1.0 per action\n
